System Pipeline & Data Flow

Four stages executing locally on CPU cores with zero external network dependencies.

Stage 1 Loopback Capture

Audio Ingestion

Captures opponent speech directly from Discord, Zoom, or web browser calls using WASAPI loopback. Audio arrays remain solely in volatile RAM.

Stage 2 INT8 CPU

Whisper Transcription

faster-whisper quantized on CPU. Discards hallucinated fillers, silences, and background chatter in sub-500ms bursts.

Stage 3 Ollama Local

Fallacy Classification

Interfaces with local model weights (qwen2.5-coder:3b) to evaluate premises and generate crisp, under-30-word refutations.

Stage 4 PyQt6 HUD

Desktop Overlay

Lightweight floating widget hovering above active applications with live audio energy meters and latency telemetry.

Designed for real-time arguments.

Conversations move faster than memory. When an opponent shifts premises, uses a false dilemma, or attacks character rather than evidence, you usually realize it seconds after the moment has passed. Elenchus runs quietly in the background, listening to system audio, parsing arguments into formal logic, and displaying targeted refutations directly in your peripheral field of view before you take your turn to speak.

Peak resident memory < 380 MB RSS (CPU quantized)
Speech chunk transcription ~ 550 ms on CPU
External network transmission Zero bytes (fully airgapped)
Binary digest verification Cryptographic SHA-256

Distribution & Quick Start

Single-command standalone installers configured with automated cryptographic SHA-256 checksum verification.

Windows PowerShell 1-Line Installer
elenchus-windows-x86_64.exe
>irm https://github.com/Asifdotexe/elenchus/releases/latest/download/install.ps1 | iex

Downloads standalone executable directly to $env:LOCALAPPDATA\Programs\Elenchus, verifies cryptographic SHA-256 release digest, and configures user PATH automatically.
