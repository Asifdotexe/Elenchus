Local-First Architecture

Engineered for sub-second Socratic clarity.

01 / Dual-Channel Audio Ingestion

Captures your physical microphone or captures your opponent directly over Discord, Zoom, or browser audio via WASAPI loopback. Audio never leaves local RAM.

02 / Local INT8 Speech Recognition

faster-whisper quantized on CPU for zero VRAM consumption. Discards hallucinated fillers, silences, and background music in sub-500ms bursts.

03 / Socratic Reasoning Daemon

Interfaces with local Ollama weights (qwen2.5-coder:3b). Incomplete thoughts and rhetorical fillers are dropped before generating crisp, under-30-word counters.

04 / Translucent HUD Overlay

Minimalist PyQt6 card floating permanently atop your screen. Styled with dark directional lighting and Monochart audio activity meters.

Deploy in one command. Zero runtime dependencies.

Six-Phase Defensive Security Rigour

Zero Unresolved Leads
Prompt Injection Fencing

All speech transcripts are bounded in <opponent_statement> tags. System prompt Rule 6 enforces strict instruction isolation to prevent adversarial voice overrides.

Qt PlainText Enforcement

HUD label widgets explicitly enforce Qt.TextFormat.PlainText, mitigating RichText/HTML injection, UI spoofing, or layout disruption from opponent speech.

Bounded Buffer Ceiling

Manual listening mode enforces a strict 60-second capture ceiling, auto-committing speech to prevent memory bloat and CPU freezing during large array concatenation.
